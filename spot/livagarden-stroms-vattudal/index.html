Ströms Vattudal · Hillsand, Jämtlands län

Visa på kartan

Familjeägd gård vid Ströms Vattudal i Hillsand, längs Björnvägen cirka 50 km från Strömsund. Stuga vid sjön, rum i huvudbyggnaden och ställplats; båt, kajak och bastu kan hyras.

Boende
Stuga vid sjön för 1–2 gäster (kokplatta, utedass, lakan kan hyras) och familjerum i huvudbyggnaden för 1–4 gäster med dubbelsäng, våningssäng, pentry och delad dusch/WC. Ställplats för husbil och husvagn.
Båtar
Båt kan hyras mot avgift på gården. Kajak kan också hyras.
